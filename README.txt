SS EMPIRE Professional Website
================================

Files:
- index.html
- ss-empire-logo.jpeg

How to publish on GitHub Pages:
1. Open your ss-empire-website repository.
2. Upload BOTH index.html and ss-empire-logo.jpeg to the repository root.
3. If index.html already exists, replace it with this new version.
4. Click Commit changes.
5. Go to Settings > Pages. Set Source to Deploy from a branch, Branch main, Folder /(root), then Save.
6. Wait a few minutes, then open the published Pages link.

Registration form:
The page attempts to display the supplied Google Form link inside the website. Some Google Forms short links may not work inside an iframe. If it appears blank, open your Google Form editor, choose Send > <> Embed HTML, copy the long docs.google.com/forms/d/e/.../viewform?embedded=true URL and replace the iframe src in index.html with that URL. This keeps the form embedded on the page rather than opening a separate tab.
